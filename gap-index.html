什么是 GAP Index？

GAP Index（Global Assessment of Proficiency）是一项专业的个人财商评估工具，帮助你全面了解自己在财务管理、投资决策和风险认知方面的真实水平。

通过 20 道精心设计的题目，GAP Index 会在 5 分钟内帮你完成以下分析：

  • 财务健康度评估 — 了解你当前的财务状况处于什么阶段
  • 投资人格画像 — 你是稳健型、平衡型还是进取型投资者？
  • 风险偏好分析 — 你真正能承受多大风险？心理和实际是否匹配？
  • 财商短板诊断 — 哪些方面需要提升，避免踩坑
  • 个性化建议 — 基于你的测试结果，给出适合你的投资方向建议

为什么你应该做这个测试？

很多投资亏损，不是因为市场不好，而是因为不了解自己：

  • 明明风险承受能力有限，却追高买了高波动产品
  • 明明适合长期持有，却频繁进出导致亏损
  • 明明应该多元化配置，却把所有资金放在一个篮子里
  • 明明对某个领域一知半解，却盲目自信投入重资

GAP Index 帮你建立清晰的自我认知，让你的投资决策更有底气。
